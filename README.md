# Evangadi Forum – Frontend

The **Evangadi Forum Frontend** is a modern web interface for the Evangadi Forum platform.  
It allows users to register, log in, ask questions, view answers, and interact with the community through a clean and responsive UI.

---

##  Features

- User authentication (Sign-up & Sign-in)
- Responsive Header and Footer navigation
- Home page displaying forum content
- Question and Answer pages with API integration
- Form validation for better user experience
- Fully responsive design

##  Routing

The application uses **React Router** for seamless navigation between pages:
- `/` → Home
- `/login` → Sign-in
- `/register` → Sign-up
- `/question/:id` → Question page
- `/answer/:id` → Answer page
- `/about` → About page
